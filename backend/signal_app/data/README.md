# Industry codes

Signal validates model suggestions and user edits against these code and title catalogs. The NAICS catalog comes from the Census Bureau’s 2022 structure workbook. The SIC catalog comes from the SEC’s EDGAR SIC table and pads codes to four digits. The code titles identify classifications. The model proposes whether those classifications fit the ICP, and a human approves that proposal.

- [Census Bureau 2022 NAICS structure](https://www.census.gov/naics/2022NAICS/2022_NAICS_Structure.xlsx)
- [SEC Standard Industrial Classification code list](https://www.sec.gov/search-filings/standard-industrial-classification-sic-code-list)
